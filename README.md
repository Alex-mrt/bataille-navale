Bataille Navale 

Ce projet est un projet fait en terminal reprenant le jeu Bataille Navale, développée en Python.   
Le projet a été réalisé à deux durant mon année de première, en utilisant l’IDE Thonny.


Rôle et contributions

Bien que l’interface principale ait été fournie, nous avons travaillé sur :
- La création desfonctions principales du jeu
- Quelques modifications et améliorations de l’interface existante

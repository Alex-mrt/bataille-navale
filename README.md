# Bataille Navale

Ce projet est une **implémentation du jeu Bataille Navale** réalisée avec **Thonny**.  
Il a été développé dans un but **pédagogique**, à partir d’une base fournie par la professeure, qui avait déjà réalisé la majeure partie de l’interface graphique.

---

## Description du jeu
- Jeu de **Bataille Navale** sur grille
- Le joueur place ses **navires** puis attaque la grille adverse
- Objectif : **couler tous les navires ennemis**
- Interactions gérées à l’aide de la **souris et des clique droits**
- Logique du jeu implémentée par moi et mon camarade à partir de l’interface existante malgré quelques amélioration de l'interface de ma part et de celle de mon camarade
- Jeu ou l'ordinateur place de façon aléatoire les navires et tire de façon intelligente 

---

## Technologies utilisées
- **Thonny**
- Langage : **Python**

---

## Comment lancer le projet
1. Télécharger et installer **Thonny**
2. Ouvrir le fichier `interface_tk.py` avec Thonny
3. Cliquer sur **Run** pour lancer le jeu
